# Reference collection

Repository design was informed by [AL-Copilot-Skills-Collection](https://github.com/fernandoartalf/AL-Copilot-Skills-Collection), by Fernando Artigas Alfonso and its contributors.

Reviewed local snapshot: `a3edaa0c6bf49c9b4c702aa625295f2085b4bc12`.

Patterns adopted: independent skill folders, supporting references loaded as needed, a discoverable skill catalog, documented contributions, and installation guidance. Edhate's installer, validator, workflow, and integration references are independently written. The upstream skills and extension are not bundled or rebranded here.

The reference collection uses the MIT license. Future imports must preserve the applicable copyright and license notices and record source revisions. Referencing that collection does not license Edhate's original contributions; a maintainer still needs to select this repository's license.
